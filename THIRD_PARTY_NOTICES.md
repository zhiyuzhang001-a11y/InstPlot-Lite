## Bundled interface fonts

InstPlot Lite embeds the following font subsets so the interface remains
readable without requiring users to install system fonts:

- `InstPlotSans-Latin.ttf` is derived from Liberation Sans 2.1.5. It is
  licensed under the SIL Open Font License 1.1. The subset was renamed to
  InstPlot Sans to comply with the upstream Reserved Font Name requirement.
  The complete license is included as `OFL-Liberation.txt`.
- `InstPlotSansSC-Level1.otf` is derived from Noto Sans SC. It is licensed
  under the SIL Open Font License 1.1. The complete license is included as
  `OFL-Noto-Sans-SC.txt`.

The font files are embedded application resources and are not installed as
system fonts.
