# InstPlot Lite v0.3.5（未签名预览版）

此版本完善了更新入口和更新弹窗的界面，并将发布过程改为一次启动后由 GitHub 自动完成。

## 主要变化

- 左侧数据栏底部仅显示小号版本号；点击版本号可手动检查更新，不再占用工具栏或显示额外按钮文字。
- 更新提示、下载进度和错误信息使用主窗口中央的弹窗显示。
- 普通代码提交只运行三平台质量检查；正式发布才执行三平台打包，避免同一版本重复构建。
- 一次发布任务会自动执行格式和 Clippy 门禁、三平台测试与打包、Windows 安装和应用内更新测试、GitHub Release 创建、OSS 签名上传及公网验证。
- 发布脚本会阻止未提交的代码、资源、打包、CI 和发布说明变更，同时允许无关的本地研究文档和临时数据存在。

## 更新说明

Windows v0.3.3 及后续版本可从应用内直接更新到本版本。v0.3.2 因旧更新器的 64 字节签名边界问题，仍需手动覆盖安装一次 v0.3.3 或更高版本。

## 安全提示

此预览版尚无 Windows Authenticode 或 Apple Developer ID 商业签名，因此 Windows SmartScreen 和 macOS Gatekeeper 仍可能显示未知发布者提示。Windows 应用内更新会独立验证 Ed25519 签名、文件大小和 SHA-256。
