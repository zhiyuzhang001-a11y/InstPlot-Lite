# InstPlot Lite v0.3.4（未签名预览版）

此版本让 Windows 更新入口和当前版本更加容易找到，并正式启用自动化 OSS 发布链路。

## 主要变化

- 将“检查更新”从顶部工具栏移到左侧数据栏底部，同时显示当前版本号；窄窗口会将其放在数据控件下方。
- v0.3.3 及后续 Windows 版本可以从应用内检查、下载、验证并覆盖安装新版本。
- GitHub Release 完成后自动签名并上传 Windows 安装包、版本签名和更新清单到阿里云 OSS，再从公网回读验证 Ed25519 签名、文件大小和 SHA-256。
- Windows 最大化状态继续使用可同时打开、移动和分别关闭的嵌入式工具窗口。
- macOS 继续仅提供 Apple Silicon 版本，不再构建 Intel 版本。

## v0.3.2 用户须知

v0.3.2 的更新器把恰好 64 字节的有效 Ed25519 签名误判为超过读取上限，因此不能通过应用内更新升级。请手动下载本版本的 Windows 安装包并直接覆盖安装；完成这一次手动升级后，后续版本即可使用应用内自动更新。

## 安全提示

此预览版尚无 Windows Authenticode 或 Apple Developer ID 商业签名，因此 Windows SmartScreen 和 macOS Gatekeeper 仍可能显示未知发布者提示。Windows 应用内更新会独立验证 Ed25519 签名、文件大小和 SHA-256，拒绝被替换或损坏的安装包。
