# InstPlot Lite v0.3.8（未签名预览版）

此版本在不改变数据处理、拟合、导入导出和更新流程的前提下，完成代码结构整理、界面统一和跨平台图标更新。

## 主要变化

- 重新组织应用、数据读写、处理、拟合和界面模块，减少重复代码并明确功能边界，便于后续维护。
- 主窗口、侧栏、状态栏以及数据处理、曲线拟合、数据导出窗口采用统一的黑色视觉体系和间距规则。
- 所有可用功能按钮增加清晰的悬停和按下反馈；禁用按钮继续保持明确的禁用状态。
- Windows 最大化和系统全屏下的工具窗口继续支持独立打开、移动、置顶和关闭。
- 统一 Windows、macOS、Linux、安装包和程序窗口使用的黑白曲线 `InP` 图标。
- 保持数据处理覆盖/保留、批量曲线处理、拟合结果关联、撤销/重做以及多格式导入导出的现有行为。

## 自动验证

- Rust workspace 格式检查、Clippy 和全部测试。
- Windows 安装、覆盖更新、自动重新启动、图标资源和应用内更新端到端验证。
- macOS arm64 DMG 和 Linux DEB/便携包构建及真实文件导入检查。
- GitHub Release 产物校验和，以及 Windows OSS 更新清单、签名和公开下载验证。

## 安全提示

此预览版尚无 Windows Authenticode 或 Apple Developer ID 商业签名，因此 Windows SmartScreen 和 macOS Gatekeeper 仍可能显示未知发布者提示。Windows 应用内更新会独立验证 Ed25519 签名、文件大小和 SHA-256。
