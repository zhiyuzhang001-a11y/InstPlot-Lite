# InstPlot Lite v0.3.2（未签名预览版）

此版本集中完善多曲线数据处理、拟合结果闭环、导出选择和小窗口交互，并为 Windows 加入安全的一键更新基础。

## 主要变化

- 数据处理支持当前曲线或多选曲线，公式根据 `x`/`y` 引用修改对应坐标，系数和拟合初值支持分数、括号与表达式。
- 拟合方程、简洁系数和 R² 在主界面持续显示；导出后重新导入仍能恢复原始曲线与拟合曲线的关联和叠加。
- CSV、TSV、TXT、DAT 和 XLSX 支持选择数据集和列；多数据集可合并或分别导出，分区文本可以无损重新导入。
- 修复全屏工具窗口、滚动区域、曲线显隐保持、坐标轴间距和极大/极小数值刻度显示。
- Windows 版本启动后会静默检查经过 Ed25519 签名的 OSS 更新清单；发现新版时可点击“更新并重启”，下载的安装包还会验证大小和 SHA-256。
- macOS 继续仅提供 Apple Silicon 版本，不再构建 Intel 版本；macOS 和 Linux 不访问 OSS 更新服务。

## 安全提示

此预览版尚无 Windows Authenticode 或 Apple Developer ID 商业签名，因此 Windows SmartScreen 和 macOS Gatekeeper 仍可能显示未知发布者提示。Windows 应用内更新使用独立的免费发布签名验证，不能消除 SmartScreen，但能够拒绝被替换或损坏的更新文件。

首次安装 v0.3.2 仍需手动下载安装包。安装此版本后，未来的 Windows 版本即可使用应用内更新。
