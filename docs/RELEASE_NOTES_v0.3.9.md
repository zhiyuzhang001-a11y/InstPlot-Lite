# InstPlot Lite v0.3.9

修复科学数据在极小数值或微小变化范围内的坐标轴显示，并完善 macOS 本地替换安装。

## 修复

- X/Y 轴刻度间距小于浮点 EPSILON 时，仍生成数字刻度和网格线；原始数据、拟合和交互坐标保持原单位。
- 小基线叠加微小变化时也支持“基准＋变化量”，避免刻度过长或重复。
- 深度放大时保留小于 1e-9 的刻度精度，并去除基准值中的浮点尾数。
- 避免极端量级下显示倍率下溢或网格粗刻度间距溢出。
- macOS 本地安装使用经过验证的隐藏暂存目录替换正式 App，清除打包暂存 App，并重新登记 LaunchServices 与 Spotlight，保持唯一正式安装。

## 验证

- 本地 130 项工作区测试、Clippy、格式检查通过。
- 实际绘图及 PNG 导出验证双轴小数值、大基线叠加微小变化和零常数列。
- 发布工作流继续执行跨平台构建、安装验证、Windows 覆盖更新与重新启动检查，以及 OSS 公网签名、大小和 SHA-256 校验。结果以本版本 GitHub Actions 记录为准。

此预览版尚无 Windows Authenticode 或 Apple Developer ID 商业签名。Windows 更新器继续独立验证 Ed25519 签名、安装包大小和 SHA-256。
