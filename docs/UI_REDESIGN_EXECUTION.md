## 1. 执行原则

1. 一次只处理一个视觉区域。
2. 每个工作包开始前确认允许修改的文件。
3. 先记录当前真实效果，再修改代码。
4. UI 绘制只返回现有 Action 或 Response，不新增业务副作用。
5. 每个工作包完成后运行自动测试和对应人工检查。
6. 每个稳定工作包单独提交，提交前不得包含下一阶段改动。
7. 当前工作包有任何回归时立即停止，不进入下一阶段。
8. 视觉缺陷和功能缺陷分开处理、分开提交。
9. 不用缩小字体、隐藏控件或取消功能来解决布局问题。
10. 不以 macOS 正常代替 Windows 验收，也不以编译通过代替 GUI 验收。
11. “测试通过”只证明没有功能回归，不等于视觉目标完成；每个确认点必须同时检查
    层级是否清楚、变化是否可见、是否仍是一排同权重灰色控件。
12. 应用外壳保持中性灰阶；除曲线和错误/危险状态外，不新增彩色填充。

## 4. 标准自动检查

每个工作包至少运行：

```sh
cargo fmt --all -- --check
cargo test --workspace --locked --all-features
cargo clippy --workspace --locked --all-targets --all-features -- -D warnings
cargo build --release --locked --package instplot-lite
cargo run --locked -- --check tests/fixtures/smoke.csv
```

涉及图片导出边界时，还要运行：

```sh
cargo run --locked -- --open tests/fixtures/smoke.csv \
  --export-plot /tmp/instplot-ui-check.png
```

必须实际确认 PNG 存在、可读取、尺寸合理，并核对是否只包含绘图区。UI 改造可能
改变应用截图，但在绘图区视觉阶段开始前，导出的绘图 PNG 应保持原基准。
SHA-256 只允许在相同操作系统、渲染器、字体、逻辑尺寸、系统缩放和工具链下比较：

- 尺寸：860 × 703
- SHA-256：`dc8f012b5339985f7686eed9fad567287b8fe4a2527b7321a47df5e3b6f15fb1`

文本导出在格式和换行约定相同的环境中逐字节比较；XLSX 按工作表、单元格值、
类型和必要格式做语义比较，不能把 ZIP 容器字节哈希当作唯一正确性依据。

## 5. 人工测试场景编号

后续工作包引用以下固定场景，避免“看了一下没问题”但没有覆盖边界。

### 主界面

- `M-01`：常规宽屏窗口，所有工具栏按钮对齐。
- `M-02`：窗口逐渐变窄，按钮不发生杂乱换行或遮挡。
- `M-03`：接近最小宽度，数据控件仍可访问。
- `M-04`：长文件名不会撑宽侧栏，悬停可看到完整名称。
- `M-05`：X/Y 下拉框对齐，列表可滚动到底部。
- `M-06`：状态文本很长时被截断，坐标显示位置不跳动。
- `M-07`：X 轴标题、状态栏和窗口底部留白互不重叠。

### 工具窗口

- `T-01`：分别打开导出、处理和拟合窗口。
- `T-02`：三个窗口同时打开，互不替换。
- `T-03`：移动两个窗口，不抖动、不自动跳回。
- `T-04`：点击已打开功能，只把对应窗口调到最前。
- `T-05`：关闭任一窗口，另外两个保持状态。
- `T-06`：窗口缩小到需要滚动，所有内容仍可访问。
- `T-07`：滚轮和滚动条都可以滚动。
- `T-08`：下拉菜单打开后可以滚动并选择最后一项。
- `T-09`：从最大化/全屏恢复普通窗口，输入和选择不丢失。
- `T-10`：模式切换后，各窗口分别保持打开状态、滚动位置和键盘焦点；关闭一个
  窗口不影响另外两个。
- `T-11`：嵌套滚动区的稳定唯一 ID 不冲突，滚轮作用于指针所在区域。

### 导出窗口

- `E-01`：全选后全不选，不退出、不崩溃。
- `E-02`：大量数据集和大量列均能滚动。
- `E-03`：选择摘要和导出按钮始终可见。
- `E-04`：五种格式的文件选择器和扩展名不变。
- `E-05`：组合/分开导出和重新导入闭环不变。

### 数据处理窗口

- `P-01`：当前曲线名称正确显示。
- `P-02`：多选曲线选择与执行规则不变。
- `P-03`：所有功能区在小窗口中可访问。
- `P-04`：`x`、`y`、分数、括号和函数公式正常。
- `P-05`：覆盖原列与保留派生列规则不变。
- `P-06`：处理后曲线隐藏状态不变。
- `P-07`：撤销与重做完整恢复。

### 曲线拟合窗口

- `F-01`：所有拟合类型和范围选项可见。
- `F-02`：长公式自动换行，不被左右裁剪。
- `F-03`：大量参数使用正常字号且完整显示。
- `F-04`：公式、参数和 R² 具有清晰层次。
- `F-05`：多选曲线分别拟合，不合并数据。
- `F-06`：同一目标重新拟合只替换对应旧结果。
- `F-07`：拟合结果与源曲线关联和导出闭环不变。

### 绘图与可见性

- `G-01`：点击图例同时隐藏/显示线和点。
- `G-02`：仅保留一条曲线后执行处理，其他曲线不自动显示。
- `G-03`：滚轮缩放方向、右键平移和复位视图不变。
- `G-04`：左键点选、吸附、框选和删除确认不变。
- `G-05`：坐标轴普通数值、科学计数法和大基准小变化显示正确。
- `G-06`：导出 PNG 不包含工具栏、侧栏或状态栏。

## 停止与回退条件

出现以下任一情况时立即停止：

- 自动测试、Clippy 或 Release 构建失败。
- 任一导入、导出、处理或拟合结果改变。
- 曲线、拟合、窗口或滚动区域 ID 改变。
- 隐藏曲线重新出现。
- 全选/全不选导致崩溃或窗口退出。

- 下拉框、菜单、输入框或滚动区域不可用。
- 小窗口存在无法访问的控件。
- 坐标轴标题、状态栏或刻度发生非预期裁剪。
- PNG 导出包含应用控件或边界变化。
- 只能通过改写业务逻辑才能继续视觉修改。
