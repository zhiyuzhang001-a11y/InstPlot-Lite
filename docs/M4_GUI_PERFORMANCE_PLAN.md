- 基准波动无法通过固定种子、预热和中位数控制，需要先修订测量合同。

## M4.3 worker 合同

1. M4.3.1 先新增 GUI 无关业务的 Qt 任务控制器：工作函数接收协作取消令牌；成功、失败、取消回调只在
   controller 所属主线程执行；任务异常不得泄漏或发布部分结果。
2. controller 持有任务身份和回调，支持单项/全部取消、活动计数和有界关闭等待。第三方阻塞调用不能
   被强杀；取消后必须丢弃其晚到结果，并在关闭时等待已启动工作安全退出。
3. M4.3.2 首先接入耗时最高且边界最清晰的文件导入；worker 只返回 `ImportResult`，`loaded_files`、
   combo、status 和绘图只能由主线程发布。M4.3.3 将嵌套在对话框内的五类拟合提取为无 Qt 核心，
   建立统一结果/错误/取消契约和正式矩阵；M4.3.4 再把超过交互阈值的拟合接入 worker。
4. 使用 Event/Qt event loop 做确定性测试，不用 sleep；窗口关闭、取消竞态、失败、新会话覆盖旧结果和
   主线程 affinity 都必须先红后绿。
