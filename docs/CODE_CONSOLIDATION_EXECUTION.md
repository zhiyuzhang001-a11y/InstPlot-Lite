## 标准检查集

### 本地必跑

```sh
cargo fmt --all -- --check
cargo test --workspace --locked
cargo clippy --workspace --locked --all-targets --all-features -- -D warnings
cargo build --release --locked --package instplot-lite
```

### 自动化行为检查

```sh
cargo run -- --check tests/fixtures/smoke.csv
```

如需在 macOS/Linux 验证图片导出，应使用临时目录，不向仓库写入生成物：

```sh
cargo run -- --open tests/fixtures/smoke.csv --export-plot /tmp/instplot-consolidation-smoke.png
```

Windows PowerShell 使用 `$env:RUNNER_TEMP` 生成目标路径，不能照抄 `/tmp`：

```powershell
$plotPath = Join-Path $env:RUNNER_TEMP "instplot-consolidation-smoke.png"
cargo run -- --open tests/fixtures/smoke.csv --export-plot $plotPath
```

必须确认产物确实存在、可读取且内容合理，不能只确认进程退出成功。

### 平台检查原则

- 不涉及平台窗口或更新器代码的纯移动，可以依靠本地检查和普通跨平台 CI。
- 涉及工具窗口基础设施时，必须运行 Windows CI 以验证编译和既有安装/更新流程，同时在真实 Windows 中人工验收窗口结果。
- 当前 Windows CI 没有 GUI 驱动，不能自动操作最大化、置顶、拖动或多窗口；不得把 CI 通过写成这些行为已经验证。
- 涉及安装或更新行为时，应停止本整合计划，另建独立任务；本轮原则上不允许涉及。
- 发布不是每个工作包的必需步骤。所有工作包完成且需要向用户交付时，才讨论版本发布。

## 停止与回退条件

出现以下任一情况时，应停止当前工作包并回到最近一个通过全部检查的提交：

- 导入或导出内容与基线不同；
- 数值处理、拟合参数或 R² 发生非预期变化；
- 曲线 ID、可见性或拟合归属丢失；
- 撤销/重做不再形成完整原子操作；
- 工具窗口不能独立打开、置顶、移动或关闭；
- 只在特定操作系统出现但尚未由真实平台验证的问题；
- 为解决借用关系需要大范围改写算法或引入共享可变状态；
- 单个工作包同时触及多个未计划的功能域。

回退后先记录原因，再缩小工作包或补充测试。不能在已知基线不一致的情况下继续后续阶段。
